# FrotaK Drive

Vou anexar diversas imagens do aplicativo atual do motorista.

IMPORTANTE

Essas imagens NÃO são referência de layout.

NÃO são referência de UX.

NÃO são referência de Design.

NÃO são referência de estrutura.

NÃO copie absolutamente nenhuma tela.

NÃO reutilize a organização dos componentes.

NÃO recrie o aplicativo existente.

As imagens devem servir APENAS para que você compreenda:

 quais funcionalidades existem

 quais informações precisam existir

 quais etapas do fluxo operacional existem

 quais ações o motorista executa

Depois disso, descarte completamente o layout existente e projete um aplicativo totalmente novo.

Objetivo

Quero criar o aplicativo oficial do motorista da FrotaK.

O resultado precisa parecer um aplicativo desenvolvido por uma grande empresa de tecnologia e publicado na App Store e Google Play.

Não quero um painel web adaptado para celular.

Quero um aplicativo nativo.

O motorista precisa sentir que está usando um aplicativo moderno e não um sistema.

O aplicativo atual possui aparência de sistema desktop adaptado para mobile.

NÃO quero isso.

Quero que você esqueça completamente essa estrutura.

Você deve reaproveitar somente:

• funcionalidades

• fluxo operacional

• identidade visual

(cor verde, branco, cinza e preto)

Todo o restante deve ser completamente redesenhado.

Tudo pensado para ser usado em movimento.

Esse é exatamente o objetivo.

Filosofia do aplicativo

O motorista nunca deve procurar uma informação.

O aplicativo deve sempre mostrar:

O que está acontecendo.

Qual a próxima ação.

Qual o status atual.

O que precisa ser feito agora.

Todo o restante fica escondido em telas secundárias.

Resultado esperado

Quero um aplicativo que, se alguém olhar sem conhecer a FrotaK, pense imediatamente:

"Esse aplicativo foi desenvolvido por uma empresa como Uber, Volvo, Scania ou Stripe."

Não quero evolução do aplicativo atual.

Quero um aplicativo completamente novo.

Use os prints apenas para identificar funcionalidades.

Ignore completamente a estrutura atual.

Redesenhe absolutamente toda a experiência do usuário pensando exclusivamente em mobile, utilizando apenas a identidade visual da FrotaK como referência.

IMPORTANTE (diretriz principal)

Antes de iniciar qualquer tela:

 Analise todos os prints apenas para mapear funcionalidades e fluxo operacional.

 Faça uma lista mental das funcionalidades existentes.

 Descarte completamente o layout atual.

 Reprojete toda a arquitetura de navegação e experiência do usuário do zero.

 Utilize padrões modernos de aplicativos mobile, e não padrões de sistemas web.

 O resultado final não pode lembrar visualmente o aplicativo atual. Deve apenas oferecer as mesmas funcionalidades de forma muito mais intuitiva, limpa e profissional, seguindo o Design System da FrotaK.
